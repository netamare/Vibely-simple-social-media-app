# Vibely

Vibely is a simple social media app I built to practice React and TypeScript. It lets users share posts, like and comment, search for people, and manage their profiles.

## Features

* Login and register

* Create and delete posts

* Like and comment

* User profiles

* Search

* Notifications

* Dark/light mode

* Responsive design

## Tech

* React
  
* TypeScript

* React Router

* LocalStorage

Open the local URL in your browser and start using Vibely.

## About

This is a practice project, so I’m using it to learn React, improve my coding skills, and build something that feels like a real app.
